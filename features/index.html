AI-Assisted Triage

Intelligent case processing from first receipt

The moment a case enters AE Connect, the AI triage engine runs a full analysis before a human reviewer touches it. Every assessment is auditable and reviewer-editable.

🧠

Automated MedDRA Coding

AI maps reported symptoms and events to the correct MedDRA Preferred Term and System Organ Class using the current MedDRA dictionary. Suggestions are presented with confidence indicators. Reviewers confirm, override, or add additional terms directly in the case record.

⚖️

Causality Assessment

Automated assessment using WHO-UMC criteria. The engine evaluates temporal relationship, dechallenge/rechallenge data, and alternative explanations to generate an initial causality rating.

🚨

Seriousness & Expectedness

Each case is automatically classified as serious or non-serious per ICH E2A criteria and expected or unexpected against the current Reference Safety Information on file.

⏱️

Regulatory Timeline Alerts

15-day and 7-day clock alerts are triggered automatically based on seriousness and expectedness classification. Your team sees submission deadlines the moment a case is triaged.

📡

Signal Detection Flagging

Cases involving potential signals, including disproportionality patterns and cluster events, are flagged for PV team review before entering the submission queue.

📝

E2B Narrative Generation

The AI generates a structured ICH E2B(R3)-compliant case narrative automatically. Reviewers edit inline and approve. No manual drafting from scratch.

Case Workflow

A validated 7-state workflow built for GxP

Every case moves through a defined, auditable lifecycle. State transitions are role-gated, timestamped, and logged, satisfying 21 CFR Part 11 and GAMP 5 requirements out of the box.

Role-Gated Transitions

State changes require the appropriate role. Reporters can submit; only Reviewers and above can approve. Admins can override with a documented reason.

📋

Full Audit Trail

Every action including field edits, state transitions, comments, and attachments is logged with user identity and timestamp. Audit logs are immutable and exportable.

📄

Case PDF Export

Generate a formatted case summary PDF at any workflow stage. Suitable for regulatory submission packages, sponsor review, and archive.
