AI-Assisted Triage

A draft from the first assessment

When you create a case or run an assessment, the workspace returns a draft. A reviewer accepts or overrides every field. The draft is decision support.

🧠

MedDRA suggestion

The draft suggests a MedDRA preferred term and system organ class, with a short reason. A reviewer accepts or overrides it. AE Connect does not grant a MedDRA license, and the suggestion is not a coding certificate. The term in Oracle Argus, ArisGlobal LifeSphere, or Veeva Vault Safety is the one your MedDRA subscription and your coder stand behind.

⚖️

Causality suggestion

The draft includes an Uppsala Monitoring Centre causality category. A reviewer accepts or overrides it.

🚨

Seriousness and expectedness

The draft suggests seriousness and expectedness. Expectedness is a suggestion to check against the current company core data sheet or the investigator brochure. AE Connect does not author or version that document.

⏱️

Reporting clock

The draft includes a reporting clock. A reviewer accepts or overrides it. AE Connect does not submit or transmit the ICSR.

📡

No signal detection

AE Connect does not flag disproportionality patterns or cluster events, and it does not run signal detection. The draft is for the single case in front of the reviewer.

📝

Narrative and E2B(R3) file

The draft can include a narrative. You can keep the full ICSR and the E2B(R3) file in AE Connect, or feed the safety database. AE Connect is not a certified connector and does not submit or transmit ICSRs.

Case Workflow

Seven case states, from receipt through close

Each case moves through these states. Reviewed means a person has accepted or overridden the draft. Recorded means the case is kept in AE Connect, or you feed the safety database you already run. Neither state submits or transmits an ICSR. These states are not a validated system, and they do not satisfy 21 CFR Part 11 or GAMP 5.

🔒

Role gated transitions

State changes follow the role. A reporter can add a report. A reviewer can accept or override the draft and move the case. An admin can override with a documented reason.

📋

Field decisions

Each field decision is stored on the account: what the draft said, whether you accepted it or overrode it, and the value you kept. Cases are scoped to that account.

📄

Case PDF export

A formatted case summary PDF for the team record. AE Connect does not submit or transmit that PDF as an ICSR.

Not a validated system

This page does not claim 21 CFR Part 11, GAMP 5, SOC 2, ISO 27001, or a HIPAA business associate agreement. The sandbox is a product workspace, not a validated computerized system environment, and not an environment we claim is qualified. IQ, OQ, and PQ have not been run. Ask QORO if you need a validation statement, and do not infer one from this page.

📦

No validation package

A validation documentation package is not included with an account. IQ, OQ, and PQ have not been run. A validation statement is a question for QORO.

🔐

No electronic signature step

This site has no electronic signature step. If your quality system requires a signature, that step belongs in the safety database your process names.

🏗️

Data handling

You paste a narrative or upload a file. The file is parsed in your browser. The file itself is not uploaded. The extracted text is sent to the API when you create a case or run an assessment. Cases are scoped to the account. This page does not claim PostgreSQL backups, encryption algorithm details, or SOC 2.

Integrations

Integrates with the safety database you already run

AE Connect can feed any safety database, including Oracle Argus, ArisGlobal LifeSphere, and Veeva Vault Safety. On that path, those products remain the system of record. You can also keep the full ICSR and the E2B(R3) file in AE Connect. A reviewer accepts or overrides the draft. AE Connect does not submit or transmit ICSRs.

Any safety database

The reviewed draft covers seriousness, a MedDRA suggestion, causality, expectedness, a timeline, and a narrative. AE Connect integrates that case with Argus, LifeSphere, Vault Safety, and other safety databases. Those products remain the system of record.
